# Документация СМИБ учебной организации
Учебный репозиторий для лабораторной работы 3 по ОСИБ.

## Структура
- 01-politika — политика ИБ верхнего уровня.
- 02-chastnye-politiki — частные политики и стандарты.
- 03-procedury — процедуры и область действия СМИБ.
- 04-instrukcii — инструкции и чек-листы.
- 05-zapisi — шаблоны доказательных записей, не пятый уровень.

## Порядок изменения
Изменение готовится в отдельной ветке с указанием причины в коммите.
Автор открывает запрос на слияние; другой студент проверяет текст.
После правки и одобрения запрос сливают в main и ставят тег редакции.
Организационное утверждение фиксируется отдельным решением руководителя.
Исходные тексты — Markdown в UTF-8; записи хранятся по номенклатуре.
Теги этого стенда учебные и сами по себе не подтверждают утверждение.
Облачный репозиторий и независимое рецензирование пока не выполнены.
